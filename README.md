FruitFly Browser

A small web browser shell with Google Search as its default search engine. Open this folder's index.html through a local web server or put the app files in the root of a public GitHub repository and install it from FruitFly OS Play Store.

Search results, web addresses, and quick links open directly in new browser tabs. Pages that block embedded previews work in their normal browser context.
